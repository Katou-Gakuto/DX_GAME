# 概要

DxLibを使用した3Dアクションゲーム「Robot_Battle」の開発

- ジャンル: 3Dアクションゲーム
- 開発規模: 200ファイル以上、C++20
- 開発期間: 個人開発
- 役割: 全工程担当

# 担当箇所

- ゲームループ、更新/描画処理
- 状態管理システム（FSM）
- リソース管理システム
- オブジェクト管理システム
- 入力システム（キーボード、コントローラー、マウス）
- 3Dカメラ、3Dサウンド、シャドウマップ
- UIシステム、シーン遷移
- 全てのマネージャークラスの実装

# 使用技術

- C++20
- DxLib（DirectXライブラリ）
- ImGui（デバッグ用UI）
- Effekseer（エフェクトライブラリ）
- Visual Studio 2022
- Windows API
- XAudio2

# システム構成

- 24のマネージャークラスによる機能分割
- 6種類の有限状態マシン（FSM）による状態管理
- 線形リスト構造によるオブジェクト管理
- 参照カウント付きリソース管理
- 非同期スレッド対応

# 実装機能

- 固定フレームレート制御（約60FPS）
- 入力システム（キーボード、コントローラー最大4台、マウス）
- 3Dカメラ制御、3Dサウンド、シャドウマップ
- シーン遷移（フェードアウト/イン）
- ローディング処理（非同期対応）
- リソース管理（画像、モデル、サウンド、エフェクト、動画）
- UIシステム（タイトル、ゲーム、リザルト）
- デバッグログシステム、ImGuiデバッグUI

# 技術的な工夫

- **高度なC++テンプレートの活用**
  - SFINAEによる型制約
  - enum class対応テンプレートオーバーロード
  - 汎用的なビットフラグ構造体（BIT_FLAG<T>）

- **デザインパターンの適用**
  - ファクトリーパターン、ステートマシンパターン、シングルトンパターン
  - 6種類のFSMによる複雑な状態管理

- **パフォーマンス最適化**
  - 線形リストによるオブジェクト管理
  - 参照カウントによるリソース共有
  - ビット演算によるフラグ管理
  - 非同期スレッドによるローディング

- **メモリ管理**
  - 参照カウント付きリソース管理
  - 遅延削除による安全なメモリ解放
