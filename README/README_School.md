# Robot_Battle

DxLibを使用して開発した3Dアクションゲームです。

## 概要

- ジャンル：3Dアクションゲーム
- 開発形態：個人開発
- 開発規模：100ファイル以上
- 言語：C++20
- ライブラリ：DxLib、ImGui、Effekseer

プレイヤーは町・ダンジョン・戦闘エリアを探索しながら敵を倒し、ステージを攻略していく3Dアクションゲームです。

## 技術的な工夫

### 状態管理

5種類のFSMを実装し、

- シーン
- キャラクター
- カメラ
- UI
- アニメーション

を独立して管理しました。

---

### リソース管理

参照カウント方式を採用し、

- モデル
- 画像
- サウンド
- エフェクト

の共有と解放を自動化しました。

---

### 入力システム

キーボード・マウス・コントローラーを統一管理する入力システムを実装しました。

入力状態は

- NOW
- DOWN
- UP

の3状態で管理しています。

---

### パフォーマンス改善

- ビット演算によるフラグ管理
- 遅延削除
- 非同期ローディング
- リソース共有

を実装しました。

---

## 苦労した点

### FSMの連携

6種類のFSMが相互に影響するため、

- シーン遷移
- アニメーション
- UI

の同期処理に苦労しました。

---

### リソース管理

参照カウントと非同期処理が同時に動作するため、解放タイミングの管理を工夫しました。
