【命名規則】
・メンバ変数
先頭にm
後ろに型
最後に役割
{型の例
	char     → c
	int      → n
	unsigned → u
	bool     → b
	string   → s
	struct   → st
	long     → l
	enum     → e
	map      → m
	VECTOR   → v

	例外
	template<typename T> struct → テンプレートTの型に準拠
	Windows API の型 → mw
}
