【命名規則】
・forやwhileのイテレーター
i_役割

・フラグの出だし
状態 → Has 
何かを行うことができるかどうか → Can
何かを行うべき → Should
真偽値を表す → is
ビットフラグ最後にBitFlagと入れる

・大きさの単位が誤解を生む変数
変数名_単位

・マクロ
アッパースネークケース（UPPER_SNAKE_CASE）
・enum
アッパースネークケース（UPPER_SNAKE_CASE）
・const変数
ローワースネークケース（lower_snake_case）
・ローカル変数
ローワーキャメルケース（lowerCamelCase）
・Class
アッパーキャメルケース（UpperPascalCase）
・関数
アッパーキャメルケース（UpperPascalCase）
・メンバ変数
ローワーキャメルケース（lowerCamelCase） & ハンガリアン記法
先頭にm
後ろに型
最後に役割
{型の例
	char     → c
	int      → n
	unsigned → u
	bool     → b
	string   → s
	struct   → st
	long     → l
	enum     → e
	map      → m
	VECTOR   → v
	関数     → fn
	クラス   → p
	void*    → p

	例外
	template<typename T> struct → テンプレートTの型に準拠
	Windows API の型 → w
}
