🌿 LaTeXでPDFにJavaScriptを埋め込むには？
LaTeXには insdljs パッケージを使って、JavaScriptをPDFに埋め込む方法があるよ。

例：PDFを開いたときにアラートを表示する
latex


コピー
\documentclass{article}
\usepackage{insdljs}

\begin{insDLJS}[openaction]{alertOnOpen}{Open Action}
app.alert("PDFを開いてくれてありがとう！");
\end{insDLJS}

\begin{document}
こんにちは、これはJavaScript付きのPDFです！
\end{document}
このコードを pdflatex でコンパイルすると、PDFを開いたときにアラートが出るよ！

latex


コピー

\usepackage{eforms}

\newpage
1ページ目の内容

\newpage
2ページ目の内容

\newpage
3ページ目の内容

\end{document}
このボタンを押すと、3ページ目（ページ番号2）にジャンプするよ！

どちらにしても、LaTeXでドット絵を描くにはいくつか方法があるよ：

🌟 方法1：tikz パッケージでドット絵を描く
LaTeXの tikz は図形を描くのにとっても便利！ドット絵も描けるよ。

例：シンプルなドット絵（顔）
latex


コピー
\documentclass{article}
\usepackage{tikz}
\begin{document}
\begin{center}
\begin{tikzpicture}[scale=0.5]
  \foreach \x in {0,1,2,3,4} {
    \foreach \y in {0,1,2,3,4} {
      \fill[gray!20] (\x,-\y) rectangle ++(1,-1);
    }
  }

  % 顔の目
  \fill[black] (1,-1) rectangle ++(1,-1);
  \fill[black] (3,-1) rectangle ++(1,-1);

  % 口
  \fill[black] (1,-3) rectangle ++(3,-1);
\end{tikzpicture}
\end{center}
\end{document}
これで5×5のグリッドに、目と口がある顔みたいなドット絵ができるよ！

❌ なぜJavaはPDFで動かせないの？
PDFの仕様では、JavaScriptはサポートされているけど、Javaはサポートされていないんだ。つまり：

JavaのコードをPDFに貼り付けても、PDFビューアでは実行できない

Javaは仮想マシン（JVM）が必要だけど、PDFにはそれがない

セキュリティ上の理由で、PDFは外部プログラムの実行を基本的に許可していない

3. JavaのコードをLaTeXで表示する

🎯 PDF内でドットを動かす方法（JavaScript + ボタン）
PDFのJavaScriptはリアルタイムアニメーションには向いてないけど、ボタンを押すたびにドットの位置を変えることで、動いているように見せることはできる！

🧪 例：ボタンでドットを右に動かす
javascript


コピー
// ドットの位置を記録する変数（グローバルに保持）
if (typeof dotX === "undefined") {
  dotX = 50;
}

// ドットを描画する関数
function drawDot() {
  var f = this.getField("dot");
  f.rect = [dotX, 700, dotX + 10, 710]; // [left, bottom, right, top]
}

// ドットを右に動かす
dotX += 10;
drawDot();
このコードをボタンに割り当てて、押すたびに dotX が増えて、ドットが右に動く感じになるよ！

🧩 実装の流れ（Adobe Acrobat Pro）
フォームを準備ツールで、透明なボタン（名前：dot）を作る

別のボタンを作って、上のJavaScriptを「アクション：JavaScriptを実行」に設定

PDFを開いてボタンを押すと、ドットが右にスライド！

⚠ 注意点
JavaScriptはPDFビューアによって動作が異なる（Acrobat Reader推奨）

アニメーションのように自動で動かすことは難しい（タイマーが制限されてる）

でも、ボタン操作で動きを再現するのは十分可能！

もし「自動で動かしたい」とか「複数のドットを動かしたい」っていうアイデアがあるなら、それに合わせてコードを一緒に考えるよ！

✅ 1. LaTeX（+ insdljs パッケージ）

✅ 2. PDF-XChange Editor（Windows用の無料PDFエディタ）
このツールは、Adobe Acrobat Proほど高機能ではないけど、フォームやJavaScriptの一部編集に対応してるよ。

ボタンにJavaScriptを割り当てる

ドキュメントアクションを設定する（開いたときの動作など）

ただし、一部のJavaScript機能は制限されているから、複雑な処理は難しいかも。

✅ 3. LibreOffice Draw + 手動でJavaScript追加
LibreOffice DrawでPDFを編集して、その後に外部ツール（例：qpdfやpdftk）でJavaScriptを埋め込むという方法もあるけど、これはかなり上級者向け！

Copilot の発言
PDF-XChange Editorは、Adobe Acrobat Proの代替として人気のあるPDF編集ソフトですが、JavaScriptのサポートにはいくつかの制限があります。以下に主なポイントをまとめるね🦊📄

⚠ PDF-XChange EditorのJavaScript制限
🔒 1. 信頼された関数（trusted function）でないと一部の操作が制限される
たとえば、this オブジェクトの操作や readFileIntoStream() のような高度な関数は、信頼された環境でのみ実行可能。

そうでない場合、NotAllowedError: Security settings のようなエラーが出ることがある[1]。

🧩 2. アプリケーションレベルのJavaScriptは特定の場所に保存が必要
グローバル変数やアプリケーションスクリプトを使いたい場合は、以下のような場所に .js ファイルを保存する必要がある[1]：

C:\Program Files\Tracker Software\PDF Editor\

%appdata%\Tracker Software\PDFXEditor\3.0\

🛠 3. JavaScriptコンソールは使えるが、機能は限定的
Ctrl + J でJavaScriptコンソールを開いて、スクリプトを手動で実行できる[2]。

ただし、PDFに埋め込んで自動実行するような高度なスクリプトは制限されることがある。

✅ できること（制限内で）
ボタンに簡単なJavaScriptを割り当てる（例：app.alert()、this.pageNum = 2; など）

フォームの検証や入力チェック

JavaScriptコンソールでの手動実行

❌ 難しいこと・制限されること
自動実行（PDFを開いたときにスクリプトを走らせる）

ファイルアクセスや外部通信

高度なインタラクション（タイマー、アニメーションなど）
